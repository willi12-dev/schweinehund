## Ziel
Bevor die erste Funktion entsteht, steht das Fundament: Repo, automatische Tests,
automatischer Bau der Android-App, Server im Internet, Push-Nachrichten. Danach
läuft jede weitere Anforderung über denselben eingespielten Ablauf.

## Ablauf / Fachliches
1. Repo `schweinehund` (privat) mit `main` (live) und `entwicklung` (Arbeit).
2. Regeln übernehmen: `docs/zusammenarbeit.md` (Befehlstabelle), Anforderungs-Index,
   CHANGELOG, VERSION, deutsche Namen, keine echten Namen im Repo.
3. **Server-Gerüst** (Flask + SQLite) mit `kern/` (Fachlogik, einzige Stelle für
   Datenbankzugriffe) und `schnittstelle/` (JSON-Endpunkte für die App).
   Erster Endpunkt: `GET /version`.
4. **Datenbank-Migrationen** wie bei Zeugnis: nummerierte Schritte, vor jedem
   Schritt automatische Sicherung.
5. **App-Gerüst** (Kotlin Multiplatform, vorerst Android): eine Startseite im Design
   „weiches Grau“, die zeigt „Server erreichbar · v0.1.0“.
6. **Push-Probe:** Der Server schickt auf Knopfdruck eine Testnachricht ans Handy.

## Bedienung und Technik
- GitHub Actions:
  · **Prüfen** bei jedem Push: Server-Tests und App-Tests.
  · **App bauen** bei jedem Push auf `entwicklung`: APK als Download (Testsignatur).
  · **TEST-Umgebung** bei jedem Push auf `entwicklung` (wie bei Zeugnis): Tests → PythonAnywhere →
    Datenbanksicherung als Artefakt (30 Tage) → `/version` prüfen. PROD folgt, sobald echte Daten kommen.
  · **Zurückrollen** per „Run workflow“ mit Versionsnummer.
- PythonAnywhere: neues kostenloses Konto nur für Schweinehund (TEST).
- Firebase: Projekt nur für Push-Nachrichten (kostenlos).
- Secrets (legst du an, ich nenne nur die Namen):
  `PA_USERNAME`, `PA_API_TOKEN`, `PA_HOST`, `FIREBASE_KONTO`, `FIREBASE_APP_KONFIG`.

## Abnahme
- `python tests/alle.py` grün, auch in GitHub Actions.
- `https://<konto>.pythonanywhere.com/version` liefert `v0.1.0`.
- APK lässt sich auf dem S23 installieren und zeigt „Server erreichbar · v0.1.0“.
- Test-Push kommt auf dem S23 an. Klappt das im kostenlosen PythonAnywhere-Tarif
  nicht (gesperrte Adresse), wird das im Bericht festgehalten, mit Ausweg.
- Zurückrollen auf eine Vorversion funktioniert einmal im Probelauf.
