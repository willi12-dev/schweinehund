# Schweinehund – die Lauf-Challenge der Familie

Eine Handy-App, in der die Familie ihre Läufe sammelt – egal, in welcher Stadt gelaufen wird.
Punkte (Leistungskilometer inkl. Anstieg), Rangliste, Sonntagsshow mit Member of the Week,
Familienkarte, Chat und Horst, unser gemeinsamer innerer Schweinehund.

- **App:** Kotlin Multiplatform, zuerst Android, iPhone später
- **Server:** Flask + SQLite auf PythonAnywhere
- **Daten:** Läufe per „Teilen“ (GPX/TCX/FIT/Bild) und über Health Connect
